# Modern Angular - E-Commerce App

Aplicação web de e-commerce desenvolvida durante o estudo de Angular Moderno. O projeto simula uma loja online com funcionalidade de busca, listagem de produtos, indicação de itens em promoção e carrinho de compras.

---

## Tecnologias e Conceitos Utilizados

- **Angular** (Versão recente / Control Flow nativo `@if`, `@for`)
- **TypeScript**
- **HTML5 & CSS3 / SCSS**
- **Componentização** e boas práticas de arquitetura no Angular

---

##  Funcionalidades

- [x] **Listagem de Produtos:** Exibição dinâmica de produtos disponíveis na loja.
- [x] **Destaque de Promoções:** Sinalização visual (`On sale`) e exibição de preço original vs. preço com desconto.
- [x] **Busca de Produtos:** Campo de pesquisa para filtragem dos itens em tempo real.
- [x] **Carrinho de Compras:** Adição de produtos ao carrinho.

---

##  Como Executar o Projeto

### Pré-requisitos
Antes de começar, você precisará ter instalado em sua máquina:
